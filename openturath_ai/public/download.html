Tata Cara Pemasangan Berkas APK

  1. Unduh berkas resmi: Klik tombol unduh di atas untuk menyimpan berkas OpenTurath_AI.apk ke folder unduhan perangkat Anda.
  2. Buka pengelola berkas: Akses berkas melalui panel notifikasi browser atau buka aplikasi File Manager pada folder Download.
  3. Persetujuan sumber terpercaya: Jika sistem Android memunculkan pemberitahuan keamanan perihal sumber aplikasi yang tidak dikenal, pilih Setelan (Settings) lalu aktifkan izin Izinkan dari sumber ini (Allow from this source).
  4. Selesaikan pemasangan: Tekan tombol Pasang (Install) dan tunggu hingga proses pemindaian paket selesai.
  5. Mulai muthala'ah: Buka aplikasi OpenTurath dan mulai telusuri rujukan keilmuan Islam yang Anda perlukan.
