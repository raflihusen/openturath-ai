Panduan Pemasangan

Tata Cara Pemasangan Berkas APK

Petunjuk langkah demi langkah untuk memasang aplikasi OpenTurath secara langsung pada ponsel atau tablet Android.

LANGKAH 01

Unduh Berkas Resmi

Klik tombol unduh di atas untuk menyimpan berkas OpenTurath_AI.apk ke folder unduhan perangkat Anda.

LANGKAH 02

Buka Pengelola Berkas

Akses berkas melalui panel notifikasi browser atau buka aplikasi File Manager pada folder Download.

LANGKAH 03

Persetujuan Sumber Terpercaya

Jika sistem Android menampilkan pemberitahuan perihal sumber aplikasi yang tidak dikenal, pilih Setelan (Settings) lalu aktifkan izin Izinkan dari sumber ini (Allow from this source).

LANGKAH 04

Selesaikan Pemasangan

Tekan tombol Pasang (Install) dan tunggu hingga proses pemindaian keamanan paket selesai.

LANGKAH 05

Mulai Muthala'ah

Buka aplikasi OpenTurath dan mulai telusuri rujukan keilmuan Islam yang Anda perlukan.
