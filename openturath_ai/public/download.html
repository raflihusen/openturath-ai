Panduan Pemasangan APK di Android

  1. Unduh berkas APK: Klik tombol Unduh APK (58 MB) di atas untuk menyimpan berkas OpenTurath_AI.apk ke perangkat Anda.
  2. Buka berkas unduhan: Akses berkas melalui panel notifikasi unduhan browser atau buka aplikasi File Manager di folder Download.
  3. Izinkan pemasangan dari browser: Jika Android menampilkan dialog "Demi keamanan, ponsel Anda tidak diizinkan memasang aplikasi yang tidak dikenal dari sumber ini", pilih Pengaturan (Settings) lalu aktifkan opsi Izinkan dari sumber ini (Allow from this source).
  4. Pasang aplikasi: Kembali ke layar sebelumnya, tekan tombol Pasang (Install), dan tunggu proses verifikasi sistem Android selesai.
  5. Mulai menelusuri: Buka aplikasi OpenTurath dan mulai ajukan pertanyaan telaah literatur Islam.
